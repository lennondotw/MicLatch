🎙️ MicLatch

Prevent macOS from switching your microphone when connecting Bluetooth audio devices.

Features

  • Automatically restores your preferred input device when macOS switches it
  • Detects system-initiated switches vs. user manual changes
  • Lightweight menu bar app
  • Built-in auto-update via Sparkle
